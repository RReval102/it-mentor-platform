Тема: Образовательная платформа для IT-менторства

Этап №1. Описание предметной области

Миссия компании: Обеспечение качественного, практико-ориентированного IT-образования через прямое наставничество (менторство) для быстрого старта карьеры студентов. Главное преимущество перед конкурентами — фокус на практическую проверку заданий живыми специалистами отрасли.

Деловая концепция компании:

  1. Что получит Заказчик: Актуальные знания, проверку практических заданий, карьерные консультации, сертификат.
  2. Кто и как выступает партнером: IT-компании (в качестве площадок для трудоустройства), независимые эксперты (для составления учебных программ).
  3. Отношения с конкурентами: Временные компромиссы в виде кросс-промоушена (обмен аудиторией со смежными нишами).
  4. Что получит собственник: Прибыль от продажи курсов, капитализацию бренда.
  5. Что получат менеджеры: Профессиональный рост, премии за выполнение KPI по удовлетворенности учеников (NPS).
  6. Что получит персонал (Менторы): Дополнительный заработок, систематизацию знаний, прокачку навыков.
  7. Сотрудничество с общественными организациями: Проведение открытых профориентационных вебинаров.
  8. Отношения с государством: Участие в государственных образовательных инициативах, уплата налогов.

Структура организации:

Генеральный директор (CEO)
├── Технический директор (CTO)
│   └── Отдел разработки ИС (Программисты, Сисадмины)
├── Директор по образованию (Head of Education)
│   ├── Методисты
│   └── Менторы / Преподаватели
└── Директор по маркетингу (CMO)
    └── Отдел продаж и продвижения

Этап №2. Выявление задач решаемых с помощью ИС

Анкета для руководителя (Директора по образованию):

  1. Цели ИС: Автоматизация выдачи уроков и контроля качества проверки домашних заданий.
  2. Орг. структура: Директор -> Методисты -> Менторы.
  3. Задачи: Удобное распределение учеников по менторам, трекинг успеваемости.
  4. Последовательность действий: Студент изучает материал -> Сдает задание -> Ментор получает уведомление -> Проверяет -> Ставит оценку.
  5. Внешние организации: Платежные шлюзы для оплаты курсов, сервисы рассылок.
  6. Справочный материал: Внутренняя база знаний с эталонными решениями задач.
  7. Время на операции: Проверка одной работы занимает 10-20 минут. Пиковые нагрузки: выходные дни.
  8. Техническое оснащение: ПК, доступ в интернет. ПО работает через браузер.
  9. Отчеты: Еженедельный отчет по активности студентов и скорости ответов менторов.
  10. Удаленные объекты: 100% сотрудников работают в удаленном формате.
  11. Документооборот: Электронные сертификаты, автоматические договоры-оферты.

Этап №3. Описание общей схемы ИС

Схема доступа к данным:
Система построена на архитектуре Клиент-Сервер (SPA Web-приложение).
Среда доступа: Браузер пользователя (HTML, CSS, JavaScript).
Сервер: Backend на языке Python.
СУБД: PostgreSQL (для хранения информации о пользователях, курсах и прогрессе).

Разработка хранилища данных (Валидность данных):
В БД используются механизмы контроля целостности: уникальность логина/email, хеширование паролей, ограничения внешних ключей между таблицами Users, Courses и Homeworks. Валидация входных данных происходит на стороне клиента и сервера.

Разработка приложения (Авторизация и функционал):
Реализована ролевая модель (Студент, Ментор). Авторизация происходит с использованием сессий. Функционал включает личные кабинеты, интерактивное прохождение тестов, панель проверки работ для менторов и генерацию именных сертификатов.

Описание работы на примере скрин-форм:
1. Форма входа: Поля логин и пароль. При успешном входе система определяет роль.
2. Дашборд Студента: Карточка курса, динамический прогресс-бар, кнопка перехода к лекциям.
3. Дашборд Ментора: Список задач на проверку с индикаторами статуса.

Тестирование и нагрузка:
Произведено тестирование UI логики (выполнение тестов с верными и неверными ответами). Предполагаемая нагрузка: 1000 DAU. Система кеширует статику, обеспечивая быстрый отклик.

Этап №4. Вывод

  1. О возможностях выбранных технологий: Связка HTML/CSS/JS полностью покрывает потребности интерфейса образовательной платформы, обеспечивая динамичность без перезагрузки страниц.
  2. О тестировании и работоспособности: Система показала стабильную работу бизнес-логики (авторизация, прохождение курсов, выдача сертификатов).
  3. О расширяемости и кроссплатформенности: Web-интерфейс кроссплатформенен (работает в любом браузере на Windows, macOS, мобильных ОС). Модульная структура позволяет легко добавлять новые блоки (чаты, рейтинги).
